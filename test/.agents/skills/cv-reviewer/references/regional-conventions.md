# Regional Conventions

Use this file to set document conventions once the target market is known. Rule: **if the target country or employer location is unknown, ask.** If the user does not know, use the International default.

Source numbers refer to `evidence.md`.

## International default (bias-safe)

- Document name: "CV" (use "resume" if the user says it).
- No photo, date of birth, age, gender, marital status, religion, national ID number, or full street address [55][56][68].
- Contact line: City, Country | phone with country code (e.g. `+44 7700 900123`) | email | LinkedIn/portfolio.
- Length: 1 page for students/early career, 2 pages for experienced candidates [7][30][42]. A third page for senior or executive candidates is an **unsourced convention** in some markets (the sources above say two pages); UK and Germany expect ≤ 2 pages [43][44][42].
- Page size: A4 unless the target is North America or the Philippines (US Letter) [66].
- Dates: `Mon YYYY – Mon YYYY` with "Present" for the current role.
- Spelling: match the job ad. If there is no ad, use the user's preference. Never mix spellings in one document.
- Cover letter: 250–400 words, 3–5 paragraphs, 1 page [13][30].

## Salutations (cover letters and emails)

Rule: **if the recipient's gender or title is unknown, use the full name** ("Dear Daniel Okafor,"). Never infer gender or title from a first name. If you are not sure which part of a name is the family name (many South Indian, Arabic, Chinese, Korean, Hungarian names), use the full name as written ("Dear Priya Raman,"). If there is no name, use the unnamed form and consider asking the user to find one (the UK National Careers Service suggests checking the company website for a department head or recruiter [13]). Forms without a citation are conventions, unsourced.

| Market | Named recipient | Unnamed |
|---|---|---|
| US / Canada | "Dear Mr. Okafor," (full stop after Mr.; "Ms." for a woman) | "Dear Hiring Manager," |
| UK / Ireland / Australia / NZ | "Dear Mr Okafor," (no full stop after Mr / Ms / Dr) | "Dear Hiring Manager,". "Dear Sir or Madam" reads as dated and gendered, though the UK National Careers Service still gives it, paired with "Yours faithfully" [13] |
| Germany / Austria / Switzerland | "Sehr geehrte Frau Okafor," / "Sehr geehrter Herr Okafor,"; when unsure, "Guten Tag Daniel Okafor," [76] | "Sehr geehrte Damen und Herren," (one guide says it suits groups, so look for a name first [76]) |
| France | "Madame," / "Monsieur," (La Poste advises against adding the surname, as in "Monsieur Dupont,") [77] | "Madame, Monsieur," [77] |
| Spain / Latin America | "Estimada Sra. Okafor:" / "Estimado Sr. Okafor:" (convention, unsourced; check locally) | "Estimados señores:" (convention, unsourced) |
| Singapore / East & SE Asia | "Dear Ms Tan," (convention, unsourced) | "Dear Hiring Manager," |
| India | "Dear Ms Rao," (convention, unsourced) | "Dear Hiring Manager," |
| GCC | "Dear Mr Al Rashid," (convention, unsourced) | "Dear Hiring Manager," |

The German and French forms rest on language-usage guides [76][77], not on employer standards; the Spanish form is convention only. Use "Mr" / "Ms" / "Frau" / "Herr" only when the person's own title is known. For German, French or Spanish letters, suggest a native-speaker check.

## Sensitive disclosures

Health, disability, pregnancy, caregiving, religion and similar details are the **user's decision**. Never push disclosure and never add it on your own initiative. Giving a reason for a gap is optional, and employment-law rules differ by country: check locally. This is writing guidance, not legal advice. The UK National Careers Service says disclosing a disability in a cover letter is optional [13].

## Market-dependent fields

| Field | Include when |
|---|---|
| Work authorisation / visa line ("Authorised to work in X", "Requires sponsorship") | Applying across borders, or the job ad asks. Employers often use it as a knockout question [19]. |
| Notice period / availability | Common in UK, EU, Asia, Middle East and Australia; usually omitted in the US. Include only if useful or requested. |
| Nationality | Only if the market expects it (e.g. GCC) and the user agrees. |
| Photo | Only if the market expects it **and** the user asks. Warn that applicant tracking systems (ATS) cannot read images [27]. The Word renderer does not embed photos; the user adds one manually. |
| References | Omit by default. "Available on request" is accepted in the UK [31] but considered outdated in the US [74]. Space is better used for content. |
| Salary | Never, unless the job ad explicitly asks. |
| Languages | Always useful internationally. Use levels: Native, Fluent, Professional working, Conversational, Basic, or CEFR A1–C2. |
