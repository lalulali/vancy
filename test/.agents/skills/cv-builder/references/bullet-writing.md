# Writing Bullets: Formulas, Verbs, Metrics

> All names and numbers here are fictional; never reuse them or any figure the user did not give.

Source numbers refer to `evidence.md`.

## Formulas
| Formula | Shape | Use for |
|---|---|---|
| **XYZ** (default) | Accomplished **[X]** as measured by **[Y]** by doing **[Z]** [33][34] | Achievement bullets |
| Result-first | [Verb] [result + metric] by/through [method] | Same, tighter — lead with the number |
| CAR / PAR | Challenge/Problem → Action → Result [39][40] | Turnarounds, problem-solving |
| STAR | Situation → Task → Action → Result [31][38] | Cover letters & interviews (too long for bullets) |
| Scope | Lead/Manage [team N] for [remit] across [scale], [budget]; report to [X] | First bullet of each role |

Every achievement needs: **an outcome**, **a measure**, and **a concrete method/technical approach**. Add **timeframe** and **baseline** when possible ("from 72% to 98% in 6 months" beats "to 98%"). **Never guess or invent the method (`by doing [Z]`) or technical stack** — if a user's old CV says "Improved API latency" or "Worked on checkout", interview them to find out *how* they did it (e.g., Redis caching, query indexing, async workers, redesigning the step flow) before writing the bullet.

## Metric types (pick what is true and relevant)
Money (revenue, savings, budget, deal size, P&L) · % change · before→after · time (cycle time, hours saved) · volume (users, clients, transactions, units) · quality (error rate, defects, NPS/CSAT, uptime, audit findings) · scale (team, sites, countries) · rank/streak ("top 3 of 40", "8 consecutive quarters") · recognition (award, early promotion).

Relevance beats size: a metric must matter to the target role. Pair % with a base where possible ("+40%, from 500 to 700 accounts").

## When numbers or technical methods are missing or confidential
1. Ask the prompts in `intake-questions.md` — probe specifically for the technical approach, architecture, tools, personal ownership, and metrics before drafting.
2. Estimates must be supplied and confirmed by the user and labelled approximate (`~`, "about", ranges like "US$1–2M", ratios, or magnitude like "seven-figure"); never invent one.
3. Use scope instead of results (team, budget, request volume, system scale) if no outcome is known.
4. Use qualitative but specific outcomes ("adopted as company-wide standard", "first in region to…") only when confirmed by the user.
5. Never fabricate numbers, tools, or methods; leave `[metric?]` or `[fact?: technical method/tool used]` in the draft and flag it. Inflated or guessed technical claims fail immediately in technical interviews and reference checks [9][32].

## Verb bank (start every bullet with one; vary — no verb more than 3× per page)
- **Lead/manage**: Led, Directed, Headed, Oversaw, Managed, Supervised, Coached, Mentored, Mobilised
- **Build/create**: Built, Launched, Designed, Developed, Established, Founded, Pioneered, Introduced, Created
- **Improve**: Improved, Streamlined, Optimised, Redesigned, Automated, Modernised, Standardised, Overhauled
- **Grow**: Grew, Increased, Expanded, Scaled, Accelerated, Doubled, Boosted, Won, Secured, Closed
- **Reduce**: Reduced, Cut, Eliminated, Lowered, Consolidated, Avoided, Recovered
- **Analyse**: Analysed, Modelled, Forecast, Diagnosed, Audited, Evaluated, Identified, Quantified
- **Influence**: Negotiated, Persuaded, Partnered, Advised, Presented, Aligned, Championed
- **Deliver**: Delivered, Executed, Implemented, Shipped, Completed, Deployed, Migrated, Rolled out

Avoid as openers: Responsible for, Duties included, Tasked with, Worked on, Helped, Assisted with, Involved in, Participated in, Successfully, Played a key role, Instrumental in.

## Style rules
- ≤2 lines per bullet (≈15–30 words); no full stops required but be consistent.
- No first person ("I", "my"); implied subject.
- Numerals for all numbers (3, not three) except at sentence start; consistent currency format (US$1.2M / €1.2M).
- Spell out an acronym once if the reader might not know it; keep the job ad's acronyms if it uses them.
- No clichés without proof: "results-driven", "team player", "passionate", "dynamic", "proven track record".
